# FlowForge Automations

Portfolio de automações e integrações construídas com **n8n**, APIs, webhooks e IA.

Este repositório foi pensado para demonstrar competências úteis tanto em **vagas de automação/integration engineering** quanto em **projetos freelance**.

## Projetos

| Projeto | Problema resolvido | Tecnologias | Status |
|---|---|---|---|
| [LeadFlow](./projects/leadflow/) | Captura, validação e qualificação automática de leads | n8n, Webhook, JavaScript | ✅ MVP |
| SmartCRM | Organização de pipeline e follow-up | n8n, CRM, automações | 🚧 Planejado |
| SupportFlow | Atendimento e triagem automatizada | n8n, Telegram, APIs | 🚧 Planejado |
| DataSync | Sincronização e transformação entre APIs | n8n, REST APIs, ETL | 🚧 Planejado |
| AI Assistant | Automação com IA e recuperação de contexto | n8n, LLM, RAG | 🚧 Planejado |

## O que este portfólio demonstra

- Automação de processos de negócio
- Integração via REST APIs e webhooks
- Tratamento e transformação de dados
- Validação e tratamento de erros
- Lógica de negócio dentro do n8n
- Documentação técnica e exemplos reproduzíveis
- Construção de soluções orientadas a problemas reais

## Sobre

**FlowForge Automations** é uma identidade de portfólio focada em automação, integrações e soluções low-code/no-code com capacidade de extensão por código.

O objetivo não é apenas mostrar workflows: cada projeto parte de um problema de negócio, apresenta sua arquitetura e inclui material para reprodução e demonstração.

## Segurança

Nenhuma credencial, token, senha ou API key deve ser versionada neste repositório. Integrações que exigirem credenciais serão documentadas com placeholders e instruções de configuração.
